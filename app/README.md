# Aplicación TraceLab

Esta carpeta contiene los archivos de la interfaz gráfica del sistema TraceLab.

## Funcionalidades

- Selección de modalidad: mandalas y siluetas.
- Selección del nivel de dificultad.
- Visualización de imágenes de referencia.
- Carga de dibujos realizados por el usuario.
- Análisis de similitud visual.
- Visualización de resultados y diferencias.

## Tecnologías

- Python
- Streamlit
- Pillow
